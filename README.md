# 🍪 Cookie Consent Audit Tool

Audit GDPR compliance pentru orice website. Detectează trackers, consent managers și generează compliance score.

## Features

- 🔍 **Single URL Analysis** — analizează orice site pentru cookies și trackers
- ⚖️ **Compare Sites** — compară 2 site-uri side-by-side
- 🕵️ **35+ Trackers Detectate** — Google Analytics, Facebook Pixel, Hotjar, HubSpot, etc.
- 🛡️ **Consent Manager Detection** — Cookiebot, OneTrust, TrustArc, Usercentrics, etc.
- 📊 **GDPR Compliance Score (0-100)** — algoritm bazat pe banner, policy, opt-in, opt-out
- 📜 **LocalStorage History** — salvează analizele tale
- ⭐ **Favorites** — salvează site-urile preferate
